Overview

This project analyses historical S&P 500 stock data using Python and Pandas. The aim was to explore stock performance, volatility, risk and return, correlations, and differences between sectors.

Objectives:

Analyse average stock returns
Identify the highest and lowest performing stocks
Measure stock volatility
Explore the relationship between risk and return
Analyse correlations between stocks
Compare average returns across S&P 500 sectors
Visualise key findings using Matplotlib
